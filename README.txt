TASKLY - TO-DO / TASK MANAGEMENT WEB APP

FILES
- index.html: Home dashboard
- tasks.html: View, search, filter, complete, edit, and delete tasks
- add-task.html: Add or edit a task
- account.html: Update your local profile
- about.html: Project information
- style.css: Website styling and animations
- script.js: Task, profile, theme, and local-storage behavior

IMPORTANT FOR GITHUB PAGES
Upload all seven files directly to the repository root (the main repository page).
Do not upload the TASKLY folder itself as a nested folder. index.html should appear beside style.css and script.js.

PUBLISH
Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
Then open: https://YOUR-USERNAME.github.io/taskly-todo-app/

NOTES
Tasks and profile settings are stored in this browser using localStorage. They do not sync between different browsers or devices.
