About TASKLY

TASKLY is a simple task management web application that helps you organize your work, track progress, and remember what needs to be done.

How to use

  1. Click Add Task to create a task.
  2. Use the search bar to find a task by title.
  3. Choose All, Pending, or Completed to filter your tasks.
  4. Use the checkbox to mark a task as completed.
  5. Use the edit or delete buttons to manage your tasks.
  6. Open Account to update your name and email.

Features

＋ Add, edit, delete

Create tasks and update or remove them anytime.

☑ Completion status

Mark tasks done and track pending work.

⌕ Search and filter

Find tasks and display only the status you need.

💾 Local storage

Your tasks remain after refreshing this browser. Data is stored on this device, not synced to an account.
